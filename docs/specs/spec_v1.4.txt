0.1 Project
  FinVerse (startup + IIT Bombay ITSP 2026 project) is a realistic simulated stock market
  where students trade against AI investors and learn the theory alongside. The engine is
  a fork of ABIDES. Repository: ApratimAnand336/Abides_market_sim. Latest branch: v1.3.
  Prices are integer CENTS; variances cents^2; engine time ns. Price about $1000
  (r_bar = 100,000 c). 1 tick = 1 cent.
  Read first: docs/engine/README.md, ARCHITECTURE.md, AGENT_FUNDAMENTALIST.md,
  AGENTS_ABIDES.md, ORACLE.md, REALISM_LAB.md, KNOWN_ISSUES.md, TESTING.md,
  docs/v1.3/lab/BASELINE.md (the R2 findings) and docs/v1.3/REPORT.md.

0.2 What R2 (v1.3) established, 20 seeds, default market C-DEF (97 ValueAgents, 1000
    NoiseAgents, 2 market makers, 20 price-only fundamentalists, 12 momentum EKF)
      1-min volatility 0.71 bps; lag-1 autocorrelation +0.37; VR(5) 1.90;
      price vol / value vol 0.58; volume-volatility correlation -0.25;
      gap std $0.145, half-life 1.5 min (estimator read); spread 1 tick (p95 3);
      ValueAgents 86.7% of volume; +2% value jump: t90 about 12 min, priced through an
      emptied book side, volume -25% in the next 30 min; impact linear (beta 0.90) and
      fully transient; volume 591,000 shares/day (median).

0.3 The mechanism R3 targets (verified independently 2026-10-12, S2 seed 42)
  One minute after a +2% value jump the ValueAgents know the value is $1020.90 and 89%
  of their orders are buys, but they bid $1000.86. ValueAgent.placeOrder prices from the
  BOOK (buy at ask - U[0, 2*spread], 10% at the ask), not from its estimate: a $20
  mispricing gives the same order as a 1-cent one. The agents that supply 87% of the
  volume therefore never push the price toward value; it moves only when one side of the
  book is exhausted. This single rule explains the smooth, positively autocorrelated
  price, the stall-then-gap pricing of jumps, the negative volume-volatility correlation,
  and the linear, transient impact.
  Second finding: ValueAgents' own model uses kappa = 1.67e-15/ns, ten times the oracle's
  1.67e-16, so they expect any deviation from r_bar to shrink by the close (97.0% kept at
  11:00, 97.6% at 12:00). That is why a jump settles at 97.6%. It disappears with them.

0.4 What R3 does NOT change (kept fixed so improvements can be attributed)
  The oracle (true-value process, parameters, PregeneratedOracle) - changed in R4.
  The MomentumEKFAgent, the AdaptiveMarketMakerAgent (cold start, spread cap stay; no
  inventory limits - R4), NoiseAgent behaviour (only the budget rule of Part 5 applies),
  the news system. No tuning of anything outside the pre-registered sweep of Part 7.

3.1 Corrected gap half-life (D-R3-4)
  Problem (owner explanation, 2026-10-13): the v1.3 estimator de-means the gap within one
  6.5 h day. For slow mispricings the day's own mean absorbs part of each swing, so slow
  swings read short (true 45 min -> about 21-25 min; 90 min -> 27-29 min). One day also
  holds only a few slow swings, so readings are noisy.
  New function gap_half_life_corrected(gap, dt=1.0, lags_s=LAB_GAP_LAGS) -> dict:
    1. rho0(L) = sum_t g_t g_{t+L} / sum_t g_t^2     (NO de-meaning; gap mean is reported
                                                      separately as gap_mean)
    2. k_L = -ln(rho0(L)) / L for 0.05 < rho0 < 0.98; k = median(k_L);
       h_read = ln 2 / k / 60 min (None if no lag qualifies)
    3. Correction table (built once, cached in api/realism_halflife_table.json, committed):
       for true half-lives H in {0.5, 1, 2, 3, 5, 7.5, 10, 15, 20, 30, 45, 60, 90, 120,
       180, 240} min, simulate 200 AR(1) gaps on the 1 s grid of a 6.5 h session
       (23,401 points, started from the stationary distribution, numpy default_rng(seed=0),
       draws in the order H ascending, path by path), apply step 2, record the median
       and p10/p90 of h_read. The median must be increasing in H; if not, smooth with an
       isotonic fit and record that in DECISIONS.md.
    4. h_corrected = monotone (log-log linear) interpolation of the inverse of
       median(h_read | H). Below the table's first reading: h_corrected = h_read. Above the
       last: report ">240 min".
       h_range = the H values whose p10..p90 reading interval contains h_read (min, max).
    Returns {"h_read": ..., "h_corrected": ..., "h_range": [lo, hi], "gap_mean": ...,
             "rho0": [...], "lags_s": [...]}.
  Across seeds: report the median of h_read and apply the correction to that median as
  well as reporting the median of per-seed h_corrected.
  Keep v1.3's gap_half_life (de-meaned) for continuity: report both, labelled
  "v1.3 estimator (biased for slow mispricing)" and "corrected".
  G10 uses h_corrected from now on (dashboard and lab). Band unchanged (30-90 min).

3.2 New jump-window metrics (in jump_response; treated run only)
  one_sided_share_jump   share of 1 s grid points in [t0, t0+30 min] with an empty side
  spread_p95_jump_ticks  p95 of the two-sided spread in that window (ticks)
  spread_max_jump_ticks  max in that window
  price_path_steps       number of 1-min bars in [t0, t0+30 min] whose |return| exceeds
                         25% of J (shows "one gap" vs "steady pricing"; reported)

3.3 R3 scorecard (new function r3_scorecard(per_config_summaries) -> dict)

PART 4. THE INFORMED FUNDAMENTALIST (abides-markets/abides_markets/agents/fundamental.py)
==============================================================================
4.0 Principle and compatibility
  New constructor parameter mode: str = "price_only". "price_only" is v1.3's agent,
  byte-for-byte the same behaviour and the same random draws (I8). mode = "informed"
  activates everything in this Part. Implement informed mode in new methods; do not
  change the price_only code paths.

4.1 What the informed agent is (plain language, for AGENT_FUNDAMENTALIST.md)
  A fundamental investor with its own research. Every few minutes it gets a noisy reading
  of the company's true value (its "research"), and it also learns, with less trust, from
  the market price. It decides how much stock to HOLD from how mispriced the stock looks,
  and - the key change - it prices every order from what it believes the stock is worth,
  not from the current quotes. It also keeps a small two-sided quote around its belief,
  so the market has liquidity at a price that reflects information, including when the
  book is empty. It may short-sell and borrow within limits.

4.2 Scheduling
  Wakes: Poisson, gap = max(1 s, Exponential(wake_mean)) from the agent's random_state.
  wake_mean per agent from INFORMED_RANGES["wake_mean"] = (30.0, 120.0, "log") seconds.
  Each wake: cancel all own open orders, request the spread (as now).
  Research clock: next_research = previous research time + Exponential(T_r), drawn from
  the agent's random_state; T_r per agent from the sweep level (Part 7). First research
  time = first wake time + Exponential(T_r).

4.3 One decision cycle (on the spread response at time t)
  Step 0 (first cycle only): x_hat = oracle.observe_price(symbol, t, random_state,
    sigma_n = self.sigma_n); P = initial_uncertainty; t_last = t. Proceed to step 6 (no
    early return: an informed agent always acts on its first wake, even with an empty book).
  Step 1 Predict: dt = (t - t_last)/1e9; Q = q * sigma_f2_hat * dt; P = P + Q.
  Step 2 Research (if next_research <= t): take ONE reading
      y_r = oracle.observe_price(symbol, t, self.random_state, sigma_n = sigma_r^2)
      K_r = P / (P + sigma_r^2);  x_hat = x_hat + K_r (y_r - x_hat);  P = (1 - K_r) P
      next_research = t + Exponential(T_r)   (one reading per wake at most; a reading is
      taken at the wake time, not at next_research itself - document this)
      log RESEARCH_READING {y_r, sigma_r, K_r, x_hat_before, x_hat_after, P_after}
  Step 3 Market reading (only if bid and ask both exist): mid = (bid + ask)/2;
      append to price_log/time_log; update_sigma_f2(t, mid) (unchanged function);
      R_noise = (delta * mid)^2 * exp(lambda_er * (1 - ER))     (the v1.2 R, unchanged)
      R_m = rho * R_noise          (rho = price distrust, per agent, Part 4.6)
      K_m = P / (P + R_m); x_hat += K_m (mid - x_hat); P = (1 - K_m) P
      log EKF_UPDATE with the v1.3 keys plus "R_m", "rho", "K_m"
      (Order: predict -> research -> market. Both are standard scalar Kalman updates of
       the same state. A large rho makes the agent learn mainly from research; rho near 1
       makes it follow the price like v1.3.)
  Step 4 t_last = t. Caution update (unchanged update_caution) only if mid exists.
  Step 5 Target position (only if mid exists):
      z      = (x_hat - mid) / sqrt(P + R_noise)          (v1.2 t-statistic; uses R_noise,
                                                            not R_m)
      w_star = clip(w0 + a_max * C * tanh(z / z0), w_min, w_max)     w0 = 0.5
      W      = cash + shares * mid       (cash may be negative, shares may be negative)
      d_star = round((w_star * W - shares * mid) / mid); step cap floor(s_max W / mid);
      dead band |d| * mid >= b_f * W and |d| >= 1  (unchanged rules)
  Step 6 Prices from belief (THE key change; no reference to bid or ask):
      m = m0 + kappa_m * sqrt(P)                             (required edge, cents)
      h = m + h0                                             (quote half-width, cents)
      target order: BUY  d shares at floor(x_hat - m);  SELL |d| shares at ceil(x_hat + m)
      quotes: bid q_q shares at floor(x_hat - h); ask q_q shares at ceil(x_hat + h)
              q_q = max(1, floor(theta_q * W_ref / x_hat)), W_ref = W if mid exists else
              cash + shares * x_hat
      every price is clamped to >= 1 cent.
      A price that crosses the book executes against resting orders up to that price and
      the remainder rests at it: an informed agent that sees a large mispricing buys
      aggressively up to its reservation price and then becomes the best bid - liquidity
      at the new, informed price. Without a two-sided book the agent posts quotes only
      (this is how the market starts without ValueAgents).
  Step 7 Budget check (Part 4.5) for each order, then send: target order first, then the
      quotes. Log FUND_DECISION (v1.3 keys plus "mode", "m", "h", "x_hat") and
      FUND_QUOTES {bid_price, bid_qty, ask_price, ask_qty, blocked_sides}.
  News: apply_news unchanged (beliefs only) and the forced immediate cycle unchanged.

4.4 Why this fixes the R2 mechanism (for the docs)
  ValueAgents knew the value but quoted near the book, so price moved by book exhaustion.
  Informed agents quote around their beliefs, so the book itself sits around the market's
  consensus belief: when research moves beliefs, the quotes move and orders cross at once.
  Disagreement between agents' beliefs (different research noise, timing and trust in
  the price) makes them trade with each other: volume comes from information and
  disagreement, so it should rise when information arrives.
  For an optimal filter the belief is a martingale (its changes are unpredictable), which
  is why price changes driven by beliefs should not be autocorrelated the way book-creep
  was. Whether the CONSENSUS of many partially informed agents keeps that property is
  exactly what T1/T2 test.

4.5 Budget limits for the informed agent
  Position limits as fractions of current wealth: w_min = -0.5, w_max = 1.5 (fixed,
  module constants INFORMED_W_MIN / INFORMED_W_MAX): it may short up to half its wealth and
  hold up to 150% of its wealth in stock (borrowing the rest).
  Check per order, worst case: let n = shares held, B = total quantity of own open BUY
  orders, S = total of own open SELL orders (orders placed earlier in this same cycle;
  older orders were cancelled at the wake), p = the order's limit price,
  W_p = cash + n * p. A BUY of q is allowed only if (n + B + q) * p <= w_max * W_p; a SELL
  of q only if (n - S - q) * p >= w_min * W_p. Otherwise reduce q to the largest allowed
  integer (possibly 0: then skip and add the side to blocked_sides). If W_p <= 0, only
  orders that reduce |n| are allowed.

4.6 New parameters (abides-markets/abides_markets/configs/param_ranges.py)
  INFORMED_RANGES (new dict; also exported to the dashboard). All per agent, drawn in this
  order, AFTER the existing FUNDAMENTAL_RANGES draws of the same agent:
    "wake_mean"      (30.0, 120.0, "log")     s
    "rho"            (3.0, 100.0, "log")       price distrust (R_m = rho * R_noise)
    "m0"             (1.0, 3.0, "linear")      cents
    "kappa_m"        (0.0, 0.5, "linear")
    "h0"             (1.0, 5.0, "linear")      cents
    "theta_q"        (0.005, 0.02, "linear")   quote size, fraction of wealth per side
    "T_r"            sweep level (Part 7): per-agent log-uniform in the level's range, s
    "sigma_r"        sweep level (Part 7): per-agent log-uniform in the level's range, cents
  Unchanged ranges, also used in informed mode: er_window, delta, lambda_er, sigma_n,
  initial_uncertainty, q, gamma, k, a_max, z0, s_max, b_f, k_news. "mu" is drawn as before
  (keeps the draw order) but unused in informed mode.
  Capital: starting wealth per informed agent from the sweep level (Part 7); endowment
  floor(0.5 * wealth / r_bar) shares as now (initial_exposure 0.5).

7.4 Selection rule (pre-registered; applied mechanically by the script, printed in full)
  On 5-seed medians:
    1. Reject designs failing any limit L1, L2, L4, L5.
    2. Among the rest, maximise the number of targets passed among T1-T4, T6 (S2 only
       in screening), T5 (S2 only in screening), T7.
    3. Tie-break: minimise the sum over T1-T4 of the normalised miss
       (distance outside the target / target scale; scales: T1 0.10, T2 0.45, T3 0.90,
       T4 0.30), then maximise daily volume, then the lexically smallest design id.

APPENDIX A. FORMULA SHEET (informed fundamentalist)
==============================================================================
  predict      P <- P + q * sigma_f2_hat * dt
  research     K_r = P/(P + sigma_r^2);  x_hat <- x_hat + K_r (y_r - x_hat);  P <- (1-K_r) P
  market       R_noise = (delta mid)^2 exp(lambda_er (1 - ER));  R_m = rho R_noise
               K_m = P/(P + R_m);  x_hat <- x_hat + K_m (mid - x_hat);  P <- (1-K_m) P
  edge         z = (x_hat - mid) / sqrt(P + R_noise)
  target       w* = clip(0.5 + a_max C tanh(z/z0), -0.5, 1.5)
  prices       m = m0 + kappa_m sqrt(P);  h = m + h0
               target BUY at floor(x_hat - m), SELL at ceil(x_hat + m)
               quotes at floor(x_hat - h) / ceil(x_hat + h), size max(1, floor(theta_q W / x_hat))
  budget       (n + B + q) p <= 1.5 W_p  (buy);  (n - S - q) p >= -0.5 W_p  (sell)
  ABIDES gross |position after order (incl. open same-side)| x p <= 2 W_p
  half-life    rho0(L) = sum g_t g_{t+L} / sum g_t^2 (no de-meaning); k = median(-ln rho0(L)/L)
               h_read = ln2/k; h_corrected = inverse of the synthetic table median(h_read | H)
