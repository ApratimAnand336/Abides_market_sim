# The realism lab

*Status: skeleton (milestone L0). Each later milestone of spec v1.3 fills its sections.*

## What the lab is for

Single simulated days are not evidence: the same seed with two different true-value paths
moved the 1-minute kurtosis from 6.7–8.0 to 1.8–3.2 (spec v1.3 §0.3). The lab runs a fixed
matrix of market configurations and scenarios over **20 seeds**, measures every run with the
same code (`api/realism.py`), and grades the 20-seed medians against bands taken from a real
large-cap stock. It **measures** the market; it changes nothing an agent decides
(spec v1.3 Part 2, invariant I8).
